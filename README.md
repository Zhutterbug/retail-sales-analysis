# Maven Roasters - Retail Sales Analysis (Power BI Project)

## 📌 Project Overview
This repository contains a Power BI portfolio project analyzing the retail sales performance of **Maven Roasters**. This project was completed as part of an advanced hands-on practice and assignment in business intelligence and data modeling.

## 📊 Key Features & Analysis
- **Sales Performance by Product Group:** Evaluated total quantity sold and total revenue across categories such as Coffee, Beverages, Drinking Chocolate, and Tea.
- **Store & Staff Breakdown:** Analyzed granular sales contributions per staff member and store level.
- **Advanced DAX Measures:** Implemented complex data filtering and context transition functions including `ALLEXCEPT`, `ALLSELECTED`, and custom percentage share calculations to compare individual performance against broader dataset benchmarks.
- **Interactive Filtering:** Configured dynamic filters for `Year_ID`, `Quarter_ID`, and `store_id` to enable multidimensional business insights.

## 🛠️ Tools & Technologies Used
- **Microsoft Power BI Desktop** (Data Modeling, Power Query, DAX Measures)
- **Git & GitHub** (Version Control & Portfolio Management)
